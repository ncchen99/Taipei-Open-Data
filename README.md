## 專案結構

這個專案整理臺北市、新北市與全國政府資料開放平臺的資料集資訊，並輸出 Markdown 報表。

### 重點檔案

| 檔案 / 目錄 | 說明 |
|---|---|
| `fetch_open_data_stats.py` | 從各平臺 API 抓取資料，產生總表與主題檔案 |
| `parse_gov_export.py` | 解析 data.gov.tw 完整 CSV 匯出（XML 格式），產生統計報告 |
| `taipei_open_data_usage.md` | 臺北市總表（依瀏覽次數排序） |
| `ntpc_open_data_usage.md` | 新北市總表（依瀏覽次數排序） |
| `gov_open_data_usage.md` | 政府資料開放平臺總表（依瀏覽次數，來自 API） |
| `gov_export_stats.md` | 政府資料開放平臺完整統計報告（來自 CSV 匯出） |
| `topics_taipei/` | 臺北市「每主題一檔」 |
| `topics_ntpc/` | 新北市「每主題一檔」 |
| `topics_gov/` | 政府資料開放平臺「每主題一檔」（API，含瀏覽次數） |
| `topics_gov_export/` | 政府資料開放平臺「每服務分類一檔」（CSV 匯出，最新資料） |

## 環境需求

- Python 3.9+
- 不需安裝第三方套件（只使用標準函式庫）

## 使用方式

### 方式一：從 API 即時抓取資料

```bash
python fetch_open_data_stats.py
```

產生以下檔案：
- `taipei_open_data_usage.md`、`ntpc_open_data_usage.md`、`gov_open_data_usage.md`
- `topics_taipei/`、`topics_ntpc/`、`topics_gov/`

### 方式二：解析 data.gov.tw CSV 完整匯出

1. 至 [data.gov.tw](https://data.gov.tw/datasets/search) 下載完整匯出（XML 格式，副檔名 .csv）
2. 將檔案放在專案根目錄（檔名格式：`export*.csv`）
3. 執行：

```bash
python parse_gov_export.py
# 或指定路徑：
python parse_gov_export.py export1777687925.csv
```

產生以下檔案：
- `gov_export_stats.md`：完整統計報告（服務分類 / 品質標章 / 檔案格式 / 更新頻率 / 機關 Top 30）
- `topics_gov_export/`：每個服務分類一份 Markdown

## 欄位說明

### API 資料（fetch_open_data_stats.py）

| 欄位 | 說明 |
|---|---|
| 資料集名稱 | 資料集標題 |
| 使用次數 | 臺北市／新北市用 `use_count`；政府平臺用 `dataset_view_times`（瀏覽次數）|
| 更新時間 | 詮釋資料最後修改時間 |
| 主題分類 | API 回傳的 `topic_name` |

### CSV 匯出（parse_gov_export.py）

| 欄位 | 說明 |
|---|---|
| 服務分類 | 使用情境分類（公共資訊、交通及通訊 等） |
| 品質標章 | 白金 / 金 / 銀 / 銅 / 無 |
| 檔案格式 | CSV、JSON、XML 等（一筆可多種格式）|
| 提供機關 | 資料發布單位 |
| 更新頻率 | 不定期、每日、每月 等 |
| 詮釋資料更新時間 | 資料集最後更新日期 |
